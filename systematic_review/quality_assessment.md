# Quality Assessment

Score each study from 0 to 2 on:

1. Clear problem formulation
2. Reproducible dataset split
3. Transparent evaluation protocol
4. Appropriate baselines
5. Statistical or multi-run reporting
6. Deployment reporting
7. Code or model availability
8. Limitations and ethical discussion

Suggested interpretation:

- 13–16: High quality
- 9–12: Moderate quality
- 0–8: Limited quality
