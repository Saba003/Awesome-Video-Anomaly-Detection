# Dataset Selection Guide

- Use UCSD or Avenue for classical fixed-camera comparisons.
- Use ShanghaiTech or MSAD for multi-scene evaluation.
- Use UCF-Crime for weakly supervised long-video analysis.
- Use XD-Violence for multimodal violence-oriented evaluation.
- Use UBnormal for supervised open-set evaluation.
- Use RareAnom for rare and severe anomaly categories.
